# 1. Product Overview

Website ini merupakan website utama untuk brand digital service yang menawarkan pembuatan website, sistem penjualan, toko/katalog online, dan kebutuhan konten digital untuk bisnis.

Website tidak diposisikan sebagai "software house besar" dan tidak menggunakan komunikasi teknis seperti React, Next.js, database, cloud infrastructure, atau istilah engineering lainnya sebagai selling point utama.

Yang dijual adalah **hasil bisnis**.

Contoh:

- bisnis lebih mudah ditemukan dan terlihat profesional;
- pelanggan dapat melihat produk secara online;
- order lebih terorganisir;
- stok dan transaksi lebih mudah dikelola;
- bisnis mempunyai konten pemasaran yang konsisten.

Website harus terasa seperti **studio digital kecil yang kompeten, personal, dan profesional**, bukan startup SaaS generik.

---

# 2. Product Goals

Tujuan utama:

1. Membuat calon pelanggan memahami layanan dalam waktu kurang dari 30 detik.
2. Membuat calon pelanggan percaya bahwa layanan dikerjakan secara profesional.
3. Mengarahkan calon pelanggan ke WhatsApp.
4. Menampilkan bukti pekerjaan nyata.
5. Mendukung penjualan KD Jualan dan KD Konten tanpa membuat website terasa seperti halaman promosi SaaS.
6. Menjadi landing page yang dapat digunakan saat melakukan outbound ke UMKM.

Website tidak bertujuan untuk:

- menjelaskan teknologi secara detail;
- memiliki dashboard customer;
- checkout layanan langsung;
- account registration;
- blog pada tahap MVP;
- menggunakan banyak halaman;
- terlihat seperti agency korporat besar.

# 22. Anti AI-Slop Rules

Website tidak boleh menggunakan pola desain generik yang terlalu identik dengan website hasil AI.

## Jangan gunakan

### 1. Gradient berlebihan

Tidak ada:

purple-to-blue gradient  
neon gradient  
mesh gradient  
glowing background

Accent boleh memiliki satu warna solid.

---

### 2. Glassmorphism

Hindari card:

`backdrop-blur-xl`

dengan border transparan dan glow.

---

### 3. Pill berlebihan

Jangan membuat semua:

- tag;
- heading;
- button;
- badge;

menjadi pill.

Rounded button boleh.

---

### 4. Giant hero typography

Headline tidak perlu:

`font-size: 100px+`.

Desktop ideal sekitar:

56–72px.

Mobile:

40–48px.

---

### 5. Bento grid tanpa alasan

Jangan menggunakan bento grid hanya agar terlihat modern.

Grid digunakan kalau membantu informasi.

---

### 6. Floating UI cards

Tidak ada card dashboard random yang mengambang di sekitar hero.

---

### 7. Decorative icon overload

Hindari:

sparkles  
magic wand  
rocket  
lightbulb  
AI brain

---

### 8. Fake metric

Tidak ada:

99% Satisfaction  
100+ Clients  
10x Growth  
24/7 Support

kecuali data tersebut nyata.

---

### 9. Fake testimonial

Tidak ada testimonial sampai benar-benar mempunyai customer yang memberikan testimonial.

---

### 10. Stock photography

Tidak diperlukan untuk MVP.

Gunakan actual product screenshot.

# 27. Motion

Motion harus subtle.

Allowed:

- opacity fade;
- 8–16px translate;
- slight image reveal;
- underline/link animation;
- subtle button feedback.

Duration:

150–400ms.

Tidak menggunakan:

- parallax berlebihan;
- cursor follower;
- blobs;
- rotating text;
- continuous floating animation;
- excessive scroll animation.

Website harus tetap terasa bagus ketika seluruh animation dimatikan.

# 29. Responsive Requirements

Website harus mobile-first.

Breakpoints roughly:

- mobile: < 640
- tablet: 640–1024
- desktop: > 1024

Mobile:

- semua service menjadi single column;
- heading tidak overflow;
- CTA full-width jika perlu;
- screenshot tetap readable;
- navigation menjadi simple menu;
- WhatsApp CTA mudah ditemukan.

Target utama kemungkinan besar membuka link dari smartphone sehingga mobile UX harus menjadi prioritas.

---

# 30. Performance

Target:

Lighthouse Performance ≥ 90.

Requirements:

- image compression;
- lazy loading untuk content below fold;
- minimal JavaScript;
- no unnecessary animation library;
- no large background video;
- optimized fonts.

# 37. Core Design Principle

Jika sebuah elemen tidak membantu salah satu dari tiga hal berikut:

1. memahami layanan;
2. meningkatkan kepercayaan;
3. membuat customer menghubungi via WhatsApp;

maka elemen tersebut kemungkinan tidak diperlukan.

Website harus terasa:

**simple → intentional → professional → human**

bukan:

**flashy → futuristic → AI-generated → over-designed**.

Referensi Design: BRIGHT, Ziist, New Lemon
